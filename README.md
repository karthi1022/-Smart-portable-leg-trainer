# Portable Leg Trainer

A smart rehabilitation and resistance workout device with custom rep/set tracking and motorized resistance control via smartphone.

## Hardware & Components
- Controller: ESP32
- Sensor: Ultrasonic sensor
## Tech Stack
- **Firmware:** Embedded C
- **IoT Platform:** Blynk IoT Cloud
- **Mobile Integration:** Real-time smartphone dashboard .

## Key Features
- Live rep and set tracking with data synchronization
- Remote resistance level adjustment via mobile app controls
